

## 👋 Welcome



Hi! I’m Ivon Dinushi Mendis, and this is my interactive portfolio showcasing my projects, skills, and certifications.
This portfolio is built with Next.js, TypeScript, Tailwind CSS, and dynamically powered by the Google Sheets API.

It’s fully responsive, modern, and designed to give an immersive browsing experience. 🚀

##🚀 Features

Dynamic Content – Projects and skills are fetched from Google Sheets in real time.

Modern & Responsive Design – Built with Tailwind CSS for seamless layouts.

Optimized Performance – Next.js and TypeScript for fast, type-safe development.

Smooth Animations – Engaging transitions and interactions (via Framer Motion).

SEO Friendly – Pre-rendered pages for better discoverability.

Run the development server:
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```


Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## 🛠 Tech Stack

Framework: Next.js

Language: TypeScript

Styling: Tailwind CSS

Font Optimization: next/font

Data Source: Google Sheets API
